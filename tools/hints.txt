# Disassembler hints. Addresses are hex CPU addresses ($8000-$FFFF = PRG).
#
#   code ADDR [NAME]         extra code entry point
#   sub ADDR [NAME]          extra subroutine entry point
#   name ADDR NAME           name a ROM label or RAM variable
#   mapreg ADDR NAME         ROM address written as a mapper register (a constant, not a label)
#   comment ADDR text        comment line above ADDR (repeat for more lines; no hash signs)
#   dispatch ADDR [NAME]     "jsr ADDR" is followed by an inline .word jump table
#   inline ADDR COUNT        explicit entry count for an inline table at ADDR
#   words ADDR COUNT         table of code pointers
#   dwords ADDR COUNT        table of data pointers
#   rtstable ADDR COUNT      table of (code pointer - 1), for RTS dispatch
#   splittable LO HI COUNT [rts]   separate low/high byte pointer tables
#   data ADDR                never trace code into ADDR
#
# Names marked with a trailing "_q" are educated guesses still to be confirmed.
